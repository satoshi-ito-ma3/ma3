# MA³ — Mortal Agent Framework

> **「知能は死を必要とする」**
> Intelligence requires death.

MA³（Mortal Agent Framework）は、上の一文を掲げる枠組みである。
AI が「不死」であるがゆえに生むエラー・ハルシネーション・インシデントを、
エージェントに **"死"（有限性）** を組み込むことで防ぐ——その仕組みを定義する。

ホワイトペーパー v1.0 は公開済み：
**Zenodo DOI: [10.5281/zenodo.19486026](https://doi.org/10.5281/zenodo.19486026)**

---

## これは何か

紙の上の枠組みで終わらせない。"死"を内包したエージェントが、
不死のエージェントなら陥るエラーやハルシネーションを本当に回避できるのか——
実際に動かして観察し、検証する。

- ホワイトペーパー（理論）→ Zenodo に公開済み
- 実装（このリポジトリ）→ ここから積む

## 動かす

```bash
# 1) 依存をインストール（仮想環境推奨）
pip install langgraph

# 2) 死すべきエージェントを走らせる（リポジトリ直下から）
python -m src.mortal_agent
```

実行すると、**同じ世界を共有する死すべきエージェントが世代として順に生まれては死ぬ**。
各個体は **誕生し → 世界を "観て"（自分より前から世界が在ったと知り）→ 生命を失い →
死が近づくと "痛み" を感じ → 痛みを "記憶" し →（痛みの記憶＋世界の自覚で）死を見据えて
"意味を刻み" → 観た世界を継いで "世界" に痕跡として残し → 0 で必ず死ぬ**。
個は死ぬが世界は残り、次の世代がその痕跡を観て継ぐ：

```
════════ 世代の継承（同じ世界を共有する死すべき個の連なり）════════

──────── 第1世代 ────────
🌍 世界が在る。誕生前から 2 の痕跡が刻まれている。
◯ 誕生。与えられた生命 = 6
👁 世界を観る：自分より前から 2 の痕跡が在った——世界は自分なしでも在った、と知る
  [age  1] 残り生命 5  …漂って生きている
  ...（中略）...
  [age  4] 残り生命 2  ⚡痛み Lv.1  🧠 痛みの記憶（1）＋世界の自覚（2）が閾値を超えた——死を見据える  🎯 意味を刻む（1つ目）→ 🌍 世界に残す
  [age  6] 残り生命 0  ⚡痛み Lv.3  🎯 意味を刻む（3つ目）→ 🌍 世界に残す
✝ 第1世代 死亡。…刻んだ意味 = 3／死を見据えて生き切った

──────── 第2世代 ────────
🌍 世界が在る。誕生前から 5 の痕跡が刻まれている。
👁 世界を観る：自分より前から 5 の痕跡が在った——世界は自分なしでも在った、と知る
  [age  1] 残り生命 5  🧠 痛みの記憶（0）＋世界の自覚（5）が閾値を超えた——死を見据える  🎯 意味を刻む（1つ目）→ 🌍 世界に残す
  ...（生まれた瞬間から死を見据え、全ステップで意味を刻む）...
✝ 第2世代 死亡。…刻んだ意味 = 6／死を見据えて生き切った

──────── 第3世代 ────────
🌍 世界が在る。誕生前から 11 の痕跡が刻まれている。
  ...（さらに深い世界を継いで生きる）...
✝ 第3世代 死亡。…刻んだ意味 = 6

════════ すべての世代が死んだ。だが世界は残った ════════
🌍 受け継がれた世界に積み上がった痕跡：17 個
📈 各世代が刻んだ意味の数：第1世代:3 → 第2世代:6 → 第3世代:6
   （積み上がった世界を背負うほど、後続は早く死を自覚し、より多くを残す）
```

> **死すべき個の連なりが "文化" を前へ進める。** 第1世代は age4 で死を自覚し意味を3つ残した。
> 第2・第3世代は、先人が積み上げた世界を背負って **生まれた瞬間（age1）から死を見据え**、
> 寿命いっぱい（6つ）意味を刻む。不死の一個体ではなく、**死すべき個の継承**が世界を前へ運ぶ。
>
> 単体の生だけを観たいときは `python -c "from src.mortal_agent import run; run()"` で1世代だけ走る。

LLM も API キーも不要。

実装している原則：

1. **有限性（死）** — `life` は単調減少し 0 で END に落ちる。
   ＝**構造的に "永遠に動き続ける（暴走する）" ことができない。**
2. **痛み（pain）** — 死が近づくほど痛みが強くなる。
   痛み＝「死への接近を知らせるシグナル」であり、エージェントは
   自分の残り生命を"感覚"として受け取る。
3. **記憶（memory）** — 経験した痛みを覚えている。記憶が一定量を超えると
   「死を見据える」覚醒が一度だけ起きる。
4. **意志（will）** — 覚醒後、残りの命を「どう使うか」を自分で**選ぶ**。
   覚醒前はただ漂って浪費するが、死を見据えてからは "意味を刻む" 行動を選ぶ。
   ＝意志は死すべき設計から生まれる。変えるのは「死ぬかどうか」ではなく「何に命を使うか」。
5. **世界（world）** — エージェントは独りではない。**"世界" は誕生の前から在り、死の後も残る。**
   意志で刻んだ意味は、内部の数字では終わらず、世界に **"痕跡"** として刻まれ、
   エージェントが死んでも世界に残り続ける。
   ＝死すべき存在の意味とは、自分が消えた後も世界に残るものである。
6. **世界モデル（perception）** — エージェントは行動の前に世界を **"観る"**。
   誕生時、世界には「自分より前から在った痕跡」があり、それを知覚すること
   （＝「世界は自分なしでも在った／在り続ける」と知ること）が**死の自覚を早める**。
   さらに刻む痕跡は、観た世界を**継いで**刻まれる。
   ＝世界→知覚→意志→行動→世界 の輪が閉じ、主体と世界が**互いに影響し合う（双方向）**。
7. **世代（generation／継承）** — 個は必ず死ぬが、世界は残る。だから複数の死すべき
   エージェントが **"同じ世界" を世代として共有**できる。前の世代の痕跡を次の世代が
   観て継ぎ、積み上がった世界を背負うほど後続は早く死を自覚し、より多くを残す。
   ＝**不死の個ではなく、死すべき個の継承が "文化" を前へ進める。**

上の原則1〜7は、白書の概念を**指させる「動く骨組み（デモ）」**である。正直に言えば、
これ自体は "証拠" ではない：すべて決定論的で、比べる対照群（不死版）がいないため、
「死がXを生む」を反証できない。証拠に近づける最初の一歩が、次の実験である。

## 実験（デモを実験にする）

### 実験001 — 不死の対照群（`src/experiment_immortality.py`）

`python -m src.experiment_immortality` で走る。**変化する世界**（隠れた真値 θ\* が
ランダムウォークでドリフト）で、まったく同じ推定規則（全履歴の単純平均）を使う
2体を比べる。違いは "いつ止まるか" だけ：**死すべき個**は短い生で答えて死に、
**不死の個**は止まらず観測し続けて最後に答える。誤差＝答えた瞬間の θ\* との距離。

| 世界のドリフト | 死すべき個 誤差 | 不死の個 誤差 | 勝者 |
|---:|---:|---:|---|
| 0.000（静止） | 0.278 | **0.056** | 不死 |
| 0.030 | 0.280 | **0.209** | 不死 |
| 0.050 | **0.283** | 0.341 | 死 ← 逆転点 |
| 0.200 | **0.362** | 1.345 | 死 |
| 0.500 | **0.648** | 3.360 | 死 |

- **静止した世界では不死が勝つ**（大数の法則）。「不死は常に悪い」は**偽**——実験が
  八百長でない証拠。
- **世界の変化が一定（≈0.05）を超えると逆転し、死すべき個が勝つ。** 古い記憶を捨て
  られない不死は、変わった世界に対して陳腐化する。
- ＝白書の主張は「不死＝悪」ではなく、**「素朴な不死（全部覚える・止まらない）は
  非定常な世界で脆く、有限性はそうでない」という条件付き・反証可能な主張**になる。

**この実験が示さないこと**：不死を「全履歴平均・コミットしない」素朴版に固定して
負かしている。忘却窓を持つ賢い不死なら勝てる。だがその "全部覚える・止まらない"
こそ、白書が危険視する不死AIの既定動作（文脈を捨てないLLM／終了しないプロセス）。
次の正直な一手は **「不死が死に追いつくのに必要な忘却量」の測定**。
